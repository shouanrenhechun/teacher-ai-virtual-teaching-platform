# 课堂对话修复结果

已实现此前六类问题的修复，并补充费用建模和课堂承接语处理。以下数据来自本地 Mock 的实际会话接口；未调用真实模型、未修改已有实训数据库。

## 修复前后

| 问题 | 修复前 | 修复后 |
|---|---|---|
| 数值等价与陡峭程度 | 2 与 2.0 被认为不相等，2 与 -2 被比较出绝对值大小 | Fraction 精确比较；等值和等绝对值分别处理，支持分数、有限小数、零及负零 |
| 引用或否定错误观点 | 教师辨析错误时被记为错误讲解，理解度下降 | 共享命题校验区分肯定、否定、引用与提问；后续“听懂了吗”不会掩盖前面已断言的错误 |
| 错误知识获得高分 | 错误教学组知识准确性 88 分 | 同一组 10 分；已识别的错误不被模型高分覆盖，无法判定的陈述从准确性统计排除并在报告说明 |
| 表扬打断题目 | 连续追问重新索要已给过的函数 | 从持久化教师对话恢复当前题目；社会性回应不覆盖条件，新题替换旧题；“纵轴相交的位置”回答 1、3 |
| 否定任务与能力陈述 | “不用计算”“相信你能判断”被当问题 | 否定任务按课堂管理，能力支持按鼓励；“表扬＋换个办法”保留实际追问 |
| 重复例题虚增掌握度 | 同一道题 5 次，A 理解度 68%→93% | 举例本身不增加理解度；首次有效回答后为 73%，后四轮保持 73%；证据键随快照保存，恢复后继续去重 |

费用例题“起步价八元，每公里再收两元”现在能形成 y=2x+8；后续询问八元的意义能回答截距。模型只在明确给出固定费用和单位费用时建立该关系，不猜测缺少的数值。

## 实际测试实例

教师：再比较 y=2x+1 和 y=2.0x+3，哪条更陡？

学生 A：两条直线一样陡，因为它们的斜率都是 2；截距不同只会改变上下位置。

另一个连续追问实例：

1. 给出 y=2x+1 和 y=2x+3。
2. 教师表扬“说得不错”。
3. 教师问“那它们与纵轴相交的位置呢？”
4. 学生回答：“把 x=0 代入，y 分别是 1、3。这就是与纵轴相交时的纵坐标。”

## 验证

- 完整后端回归：478 项通过，1 条既有测试客户端依赖弃用警告。
- 原 33 组、114 轮对话全部成功完成，24 组关键检查通过，覆盖学生 A/B/C。
- 新增回归包括等价数值、分句立场、错误准确性、0～6 轮社会性插入、新题替换、否定动作、混合任务、快照恢复后的重复证据、费用建模。
- 原来“举例立即增加理解度”的旧测试改为验证教学机会与学习证据分离；其他既有测试保持通过。
- 接口成功和关键检查通过不等于每句回复都是最佳教学回应。Mock 仍可能返回保守、通用的请求提示。

## 文件与边界

- `dialogue_review_before_fix.json`：修复前记录。
- `dialogue_review_results.json`：当前修复后的记录。
- `run_dialogue_review.py`：重跑脚本，自动使用临时数据库并校验关键结果。
- `../tests/test_review_fixes.py`：新增回归测试。

数学解析与命题校验是有边界的规则实现，不是通用自然语言证明器；复杂公式、任意生活建模和跨学科命题尚不保证覆盖。真实模型使用相同的后端评分保护、状态去重和题目上下文提示，但生成内容本身尚未联网验证。旧会话历史快照和已有评价不会自动重写；旧快照没有证据键时，从后续新轮次开始积累去重信息。
