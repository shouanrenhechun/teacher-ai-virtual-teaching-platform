# 项目可靠性与教学评价修复报告

验收日期：2026-09-21。范围为单机个人实训，一次函数与完全平方；保留原有工作区改动和页面风格。代码已实现并完成离线回归。真实模型表现和评分的教育效度仍需分别验证。

## 修复清单

| 问题 | 实施的修复 | 验证结果 |
|---|---|---|
| 数值比较与情境解释不可靠 | 共用 Fraction 解析、计算与格式化；区分斜率与斜率绝对值；精确比较分数、小数和负数；展开式按系数核验；删除移动后位置不变的矛盾表达，费用解释需要明确情境 | 数学回归通过，普通截距不再生成“起步价” |
| Mock 与 Real 流程不一致、无效回答可能污染状态 | 两个领域共用计划、生成和校验；真实会话入口已接入；最多重试一次并传递拒绝原因，再使用校验后的确定性回答；最终异常仅请求澄清且禁止累计学习证据 | 模拟 HTTP 验证正式入口的超时、无效 JSON、错误数学内容和降级元数据 |
| 鼓励后丢失题目、复述被当成掌握 | 保留有效题目、识别换题和自纠；按规范化题目与证据能力去重；完全平方纳入相同状态约束；只记下教师答案不生成独立解释证据；旧快照的去重键可升级 | 同题追问经过鼓励仍保留条件；重复解释的掌握计数不增长 |
| 次数型评分缺乏证据 | 新报告采用 rubric_version=2；五维权重保留；四个教学维度按独立任务的三项检查取平均，取值 0/0.5/1；知识只核验明确命题；支持跨轮撤回和跨轮错误诊断 | 重复表扬/同题不堆分，针对性反馈优于空泛表扬，独立解释优于复述；诊断引用先前错误与后续独立回答 |
| 测试可能写入正式库或意外调用模型 | 自动测试夹具同时隔离启动初始化和请求数据库依赖；禁止使用原始数据库连接，拦截外网连接和 DNS；默认 Mock | 完整测试使用临时目录；正式实训库未参与测试 |
| 浏览器之间可读写同一会话、旧记录自动接管风险 | 随机浏览器令牌与后端哈希归属；创建、恢复、历史、发言、结束和评价校验归属；旧记录先保持未归属，再由用户明确导入 | 两个身份无法互读写新会话；导入重试不重复迁移；首页可直接查看导入后的历史报告 |
| 长事务与并发可能覆盖状态或留下半轮对话 | 模型调用前释放事务；会话版本和活动状态 CAS；消息幂等标识；消息、行为、快照原子提交；评价保存使用短事务并复用已生成结果 | 并发发言一方 409；结束与发言竞争不产生半轮；重复消息返回已保存结果；并发评价只保留一份 |
| 前端请求和历史展示可靠性不足 | 拆分课堂、报告、历史、图表和请求；历史服务端分页、学生筛选、独立近 20 条曲线和评分版本选择；空值显示未评估；失败保留草稿；冲突刷新；UTC 时间统一；展示模式和降级信息 | 构建通过；桌面和 390px 页面检查通过；跨页、筛选、打开旧报告、刷新及冲突恢复已实测 |

第二版只有在至少三个独立实质任务、知识准确性可评估且可评估权重达到 80% 时生成总分，并按覆盖权重归一化。没有相关机会时维度为未评估；已出现机会却未回应时计入未满足。普通鼓励只作为互动记录。

每项检查保存任务、引用轮次和理由。质性建议引用评分使用的证据；模型输出 Schema 不允许新增或修改数值评分。旧版报告的原始分数保持不变，不与第二版成长曲线混算。

## 完整实训实例与原始结果

完整六轮实例位于同目录 `reliability_test_example.md`，包含教师输入、学生原样回复、状态变化、累计证据变化、五维分数和逐项引用。全部 12 段原始转录位于 `reliability_review_results.json`，案例定义位于 `classroom_acceptance_cases.json`。

该实例使用学生 C：第 1 轮暴露“b 越大越陡”的错误；第 2 轮通过同斜率对比形成初步理解；第 3 轮重复解释时，独立正确证据仍为 1；第 4 轮教师明确诊断此前混淆；第 5 轮换用负斜率新题，证据达到 2，模拟状态转为 corrected；第 6 轮解释不再重复累加。第二版训练参考总分为 **87.91**，覆盖权重 100%，三个独立任务。这是程序规则的参考输出，不代表已经验证的教师能力等级。

## 数据升级与使用

本轮没有启动或迁移正式 `backend/data/app.db`。正常启动后端时，程序会在迁移旧库前创建同目录 `*.v1.bak`，再事务升级；遇到高于当前支持版本的数据库会拒绝降级。旧会话不会被首次访问者自动接管，需点击“将旧记录导入当前浏览器”。

令牌用于本机浏览器练习隔离，不是多人平台的账号认证。保留浏览器站点数据才能继续使用原身份。

复现命令（在对应目录执行）：

```powershell
# backend
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m audits.run_reliability_review
.\.venv\Scripts\python.exe -m audits.run_real_api_smoke
# frontend
npm.cmd run build
```

## 尚待验证与剩余限制

- 没有密钥，本轮不具备真实模型质量结论。配置后需运行小批量真实验收；离线通过不能替代它。
- 第二版评分尚未经过专业教师标注与校准。语义识别和数学核验仍限定在当前两个领域；不能覆盖所有自然语言授课表达。
- 测试依赖产生一条 Starlette/httpx 弃用提醒；目前未导致测试失败。
- 历史与图表共享的按需加载模块约 512.73 kB，构建仍提示超过 500 kB。功能验收通过，进一步压缩图表依赖仍有空间。
